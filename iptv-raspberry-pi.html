IPTV Raspberry Pi einrichten – Anleitung 2026

Der Raspberry Pi 4 und Pi 5 sind energiesparende Minicomputer, die mit Kodi + PVR IPTV Simple Client zu vollwertigen IPTV-Geräten werden. 50.000+ Kanäle, 4K-Qualität und 300.000+ Filme direkt auf Ihrem Raspberry Pi.

Empfohlene App: Kodi oder VLC

Raspberry Pi ist mit LibreELEC/Kodi oder dem Desktop-Linux über VLC vollständig IPTV-kompatibel. Ideal für technisch versierte Nutzer, die ein günstiges, energiesparendes IPTV-Gerät bauen wollen.

Schritt-für-Schritt Einrichtung

Schritt 1: LibreELEC auf dem Raspberry Pi installieren

LibreELEC-Image von libreelec.tv herunterladen, mit Raspberry Pi Imager auf SD-Karte schreiben, Pi starten. Kodi öffnet automatisch.

Schritt 2: PVR IPTV Simple Client in Kodi aktivieren

Kodi → Einstellungen → Add-ons → Meine Add-ons → PVR-Clients → PVR IPTV Simple Client aktivieren → Konfiguration öffnen.

Schritt 3: M3U-URL und EPG eintragen

In der PVR IPTV Simple Client Konfiguration die M3U-URL von StreamDeutschland eintragen. EPG-URL separat im EPG-Tab eingeben. Kodi neu starten.

Schritt 4: Alternativ: VLC unter Raspberry Pi OS

sudo apt install vlc → VLC starten → Medien → Netzwerkstream → M3U-URL von StreamDeutschland eingeben. Einfacher, aber ohne EPG.

Häufige Fragen

Welcher Raspberry Pi eignet sich am besten für IPTV?

Raspberry Pi 4 (4GB RAM) oder Pi 5 für flüssige 4K-Wiedergabe. Ältere Modelle (Pi 3) funktionieren für HD-Streams.

Kann der Raspberry Pi 4K IPTV streamen?

Ja – Raspberry Pi 4 und 5 geben 4K HDR10 aus. LibreELEC mit Kodi nutzt Hardware-Dekodierung für flüssige 4K-Wiedergabe.

Welches Betriebssystem empfehlen Sie?

LibreELEC mit Kodi ist die einfachste Lösung speziell für IPTV/Media Center. Raspberry Pi OS + VLC ist flexibler für weitere Anwendungen.

Wie richte ich EPG auf dem Raspberry Pi ein?

Über den PVR IPTV Simple Client in Kodi. StreamDeutschland liefert die EPG-URL zusammen mit den Zugangsdaten.

Gibt es einen kostenlosen Test?

Ja – Testlinie anfordern, auf dem Raspberry Pi einrichten, kostenlos testen.
